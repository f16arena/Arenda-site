# Перевод мобильного приложения — задел на будущее

Здесь лежит готовая основа перевода: `i18n.tsx` (провайдер и хук `useT()`),
`i18n-ru.ts` и `i18n-kk.ts` (словари, ~590 строк каждый).

**Экраны приложения пока НЕ переведены** — владелец 23.09.2026 решил делать
сначала только сайт. Файлы оставлены, чтобы не переводить всё заново, когда
вернёмся к приложению.

Что останется сделать:

1. Обернуть `app/_layout.tsx` в `I18nProvider`.
2. Заменить строки на `t(…)` в `app/screens/*` и `app/components/ui.tsx`.
3. Там, где приходит `getMobileBootstrap()`, вызвать
   `applyProfileLocale(bootstrap.user.locale)` — язык приложения тогда совпадёт
   с кабинетом на сайте (сервер уже отдаёт это поле).
4. Добавить переключатель языка в `app/screens/more.tsx`.
5. Спорные формулировки помечены `// проверить` — их читает носитель языка.

Термины — из `docs/i18n-glossary.md` в корне проекта.
