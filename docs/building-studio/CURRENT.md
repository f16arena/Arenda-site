# Building Studio — что умеет сегодня

Снимок состояния на 18.09.2026. `ROADMAP.md` и `SPEC.md` — исходное ТЗ, заморожены;
этот файл описывает то, что реально собрано и проверено тестами.

## Из чего состоит

| Слой | Где | Кратко |
|------|-----|--------|
| Документ модели | `types/builder.ts`, `core/document/commands.ts` | zod-схема + команды с откатом (CommandStack) |
| Геометрия | `core/geometry/*` | граф стен, распознавание помещений, лестницы/пандусы, кровля |
| Правила предметной области | `lib/builder/*` | площади по внутренним граням, назначение помещений, проёмы, привязка, проверка модели |
| Чертежи | `lib/builder/drawing/*` | план, фасады, разрезы, узлы, генплан, ведомости, DXF |
| 3D-движок | `engine/*` | Babylon: стены с проёмами, перекрытия, кровля, отделка, автомебель, свет, обход |
| Интерфейс | `components/builder/*` | тулбар, панели, редактор плана (SVG), листы чертежей, витрина |

## Редактор плана

- Стены, комнаты, проёмы (двери/окна/витражи), лестницы, лифты, колонны, пандусы,
  мебель из каталога, инженерные сети, пометки и размеры.
- Привязка: узел → грань стены → «в линию» (отслеживание по своей ломаной, потом по
  остальным узлам) → угол 15° с шагом длины 50 мм → сетка 100 мм. От угла с дробной
  координатой (обведённый по скану план) стена выходит ровной: длина отмеряется от
  предыдущей точки.
- Арендные места («Островок») — всё, что сдаётся вне помещений:
  - в общих зонах: вендинг, киоск, банкомат, стойка, кофе-точка, торговая стойка;
  - на стенах: баннер и лайтбокс (цепляются к ближайшей стене, высота низа);
  - на участке: парковочные места (2,5×5,3 / 3,5×8 / мотоместо), киоск на
    территории, контейнер 20 футов;
  - на кровле: антенно-мачтовое сооружение и базовая станция — садятся на
    поверхность крыши, при смене типа кровли переезжают на новую.
  У места есть наименование, арендатор, габарит с поворотом, привязка к карточке
  помещения (кнопка «Создать карточку места» заводит её одним нажатием),
  окраска по статусу в режиме «Аренда». Ставится и правится и в плане, и в 3D;
  выделенное место двигается стрелками (100 мм, с Shift — 10 мм) и не проходит
  сквозь стены.
- Уровни: этажи, **Кровля** (тип крыши, площадь, места на ней) и **Участок**.
- Автомебель правится поштучно: «Удалить» убирает предмет (Ctrl+Z или кнопка
  «Вернуть мебель» возвращают), клик «Выбором» превращает его в обычный объект,
  который двигается мышью и стрелками.
- Подложка-скан с калибровкой, перепланировка (демонтаж/монтаж/после).
- Режим «Участок»: здание видно целиком, правится элемент любого этажа без
  переключения уровня.

## Проверка модели (`lib/builder/validate.ts`)

Панель в блоке уровней: сводка + список, клик ведёт к элементу, одинаковые
замечания собираются в строку со счётчиком.

Ошибки: арендное место вне здания, помещение без входа, проём шире стены или без стены, этаж не связан
лестницей, лестница/лифт вне здания, стена нулевой длины.
Замечания: помещение без окон, без наименования, без привязки к базе, окно во
внутренней стене, узкая эвакуационная дверь, нет отмеченных выходов, вход выше
земли без пандуса, низкий потолок, арендное место съедает эвакуационный проход
(меньше 1,2 м).

Рядом — кнопка «Подставить наименования» (`lib/builder/room-naming.ts`): типовые
имена по геометрии одним действием, Ctrl+Z возвращает.

## Чертежи (альбом — 33 листа)

Общие данные, генплан, планы этажей с экспликацией и ведомостью проёмов, планы
эвакуации (на верхних этажах путь ведёт к лестничной клетке — знак «НА ЛЕСТНИЦУ»), планы перекрытий с ведомостью плит, план кровли, перепланировка, сети
(ЭМ/ЭО/СС/ВК/ОВ), фасады, разрезы, ведомость арендных мест, **узлы и фрагменты** (А2: цоколь, примыкание
перекрытия, оконный проём, парапет или карниз — всё считается по модели).

Фасады и разрезы идут в осях (кружки с марками, диапазон в заголовке), на разрезах
показаны лестницы и лифты. Экспорт: печать в PDF и DXF (планы и виды).

## 3D

- Автомебель по назначению помещений (офис, переговорная, холл, магазин, кафе,
  техпомещение) + сетка потолочных светильников; в коридорах только свет; в
  документ не пишется, выключается кнопкой, в лёгком режиме не строится.
- Время суток: ползунок 5:00–21:00 — положение солнца, цвет света и неба, дымка,
  экспозиция; вечером в окнах загорается свет.
- Обход (Walk): рост 1,7 м, гравитация, лестницы и пандусы проходимы, стёкла и
  мебель — преграда, двери открываются кликом, сверху плашка с помещением.
- Витрина: автооблёт до первого касания, ползунок солнца и кнопка мебели,
  вписывание здания с учётом узкого экрана телефона, журнал открытий ссылки.

## Чем проверяется

- `npx vitest run` — 292 теста ядра и правил.
- `node scripts/builder-harness/build.mjs`, затем `node scripts/builder-harness/runN.mjs`
  — 12+ сценариев в реальном браузере (Playwright): редактирование, привязка,
  обход, автомебель, время суток, пандусы, проверка модели, режим «Участок».
- `npm run ci:performance-gate` — бюджеты размера, изоляция, guardrails.

## Изоляция данных

Организация → здание → этаж → помещение → арендатор, проверки в серверных
действиях; публичные ссылки-витрины с сроком и отзывом, журнал открытий (IP не
хранится, только необратимый хеш). В базе на всех таблицах включена RLS, у ролей
`anon`/`authenticated` нет грантов — подробности в `../SECURITY-ISOLATION-2026-09.md`.
