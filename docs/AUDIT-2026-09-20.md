## 1. Единый слой данных (lib/data/*) — правда из договоров

Правило: страница не пишет свой запрос «арендаторы / аренда / долг / занятость / доход».

- **lib/data/tenants.ts** — `tenantsInBuildingsWhere(orgId, buildingIds, {includeDeleted?})`,
  `RENT_INPUT_SELECT`, `softDeleteTenant()` (сейчас 2 разных пути удаления: users.ts не гасит
  начисления/оплаты/помещения удалённого арендатора).
- **lib/data/debt.ts** — `unpaidChargeWhere()`, `getDebtSummary()`, `getDebtByTenant()`,
  `ACTIVE_CHARGES/ACTIVE_PAYMENTS` для вложенных include (удалённые начисления сейчас
  попадают в **акты сверки, АВР, счета** и кабинет арендатора).
- **lib/data/occupancy.ts** — одна формула: м², только сдаваемые (RENTABLE), объекты и
  крыша/территория отдельно, этаж целиком = занято. Сейчас 9 разных формул.
- **lib/data/income.ts** — доход по оплате без депозитов, по начислению, «аренда в месяц
  по действующим договорам» (с учётом срока и каникул), без двойного счёта по зданиям.
- **lib/data/spaces.ts** — свободные помещения, `floorLabel()` (Крыша/Территория) в lib/zone-kinds.

Высокий приоритет (цифры владельца/юр. документы расходятся):
- выгрузка 1С (`app/api/export/1c`) — только основное помещение, теряет оплаты киоска/нескольких помещений;
- экспорт финансов, мобильное приложение (lib/mobile-admin.ts — свой фильтр без здания/удалённых);
- акты сверки / АВР / счета из удалённых начислений;
- кабинет арендатора: «этаж целиком» видит аренду 0;
- договоры (`/admin/contracts`) и мобильный — без ступенчатой аренды.

## 2. Единый дизайн

Есть, но не используется: `ui/select`, `ui/dropdown-menu`, `ui/sheet`, `ui/alert-dialog`,
`ui/table`, `ui/tabs` — 0 использований. Вместо них: 84 системных `<select>`, ~22 самодельных
окна `fixed inset-0`, 26 `confirm/alert/prompt`, 54 таблицы вручную, ~25 копий карточек-цифр,
35 полей даты без общего компонента.

Создать/довести: `Input` (h-9), `NativeSelect`, `Field`, `ActionMenu` (меню «⋯», не обрезается
таблицей), `Modal`/`FormModal`, `useConfirm/usePrompt`, `DatePicker`/`MonthPicker`/`PeriodPicker`,
`TableCard`, `Segmented`, `StatusBadge`, `Alert`; `StatCard size="sm"`.
Порядок: финансы → арендаторы → помещения → документы → обзор → аналитика → настройки → остальное → конструктор.
Страж: ESLint-правило против `fixed inset-0`, `window.confirm`, `<select`, `const inputCls` вне components/ui.

## 3. Тёмная тема — осталось

- публичные страницы (вход, регистрация, бронь, подписание) — светлый фон + тёмные карточки;
- страницы только-тёмные (роли, пользователи, подписка, superadmin) ломаются в светлой;
- `dark:text-slate-600` на тёмном фоне — нечитаемо (этажи, хлебные крошки);
- галочки/аватары/иконки пустых состояний без тёмного варианта.

## 4. Изоляция данных

Закрыто (`151cb6a` + security-фикс импорта): импорт выписки со всеми организациями; права
встроенных ролей правились на всю платформу (теперь — только владелец платформы); мобильные
задачи без здания — по id в любой организации; сотрудники без проверки прав (можно было сменить
пароль владельца); подпись чужого счёта/АВР; Kaspi по БИН в чужую организацию; spread-OR в
billing-batch, superadmin, мобильном поиске, data-quality; «подписан арендодателем» без права.

Осталось:
- **RolePermission по организациям** (миграция: organizationId, org+role+section) — вернуть
  организациям настройку встроенных ролей, но только у себя.
- **/demo** пускает анонима владельцем демо-организации без ограничений записи — сделать
  демо только на чтение или изолировать.
- Доступ по зданиям (сотрудник с частью зданий): генераторы `/api/{contracts,invoices,acts,
  reconciliation,handover}/generate`, архив/zip документов, `/api/admin/tenants/[id]/sections`,
  `/api/search`, страницы договоров/депозитов/рассрочек/заявок/квитанций, `listOrgPremises`.
- Подписи читаются по documentId без организации (/verify, штампы, ЭСФ, кабинет).
- Мобильное подписание сохраняет подпись без проверки CMS.
- Права: `getContractCard`, `listContractDrafts/loadContractDraft`, `getTenantDeleteBlockers`,
  `parseBankCsv`, экстренные контакты — без capability.
- Мелкое: /verify показывает удалённые, /api/health конфиг платформы владельцу, секреты
  telegram/market сравниваются не за константное время, GET-генераторы с побочными эффектами.
